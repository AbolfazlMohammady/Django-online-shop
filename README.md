## 📖 معرفی پروژه**Django Online Shop** یک پلتفرم فروشگاهی پیشرفته و کاربرپسند است که با استفاده از فریمورک Django طراحی و توسعه یافته است. این پروژه به کاربران این امکان را می‌دهد که به سادگی و با امنیت بالا، محصولات مورد نظر خود را خریداری کنند.  

---  

## 🚀 ویژگی‌های کلیدی### برای کاربران:  

- **👀 جستجو و فیلتر قدرتمند** راحت‌ترین راه برای پیدا کردن محصولات با جستجو بر اساس نام، دسته‌بندی و ویژگی‌ها.  

- **🛒 سبد خرید و خرید آسان** مدیریت ساده سبد خرید و پرداخت امن با چند کلیک.  

- **🔗 دسترسی آسان به جزئیات محصول** مشاهده اطلاعات کامل شامل قیمت، تصاویری از محصول و نظرات کاربران.  

### برای مدیران:  

- **🏷️ مدیریت محصولات** افزودن، ویرایش و حذف محصولات به‌راحتی با یک پنل مدیریتی بصری.  

- **📊 تحلیل داده‌ها و گزارش‌گیری** دریافت آمار فروش و رفتاری کاربران برای تصمیم‌گیری‌های هوشمندانه.

## 🛠️ تکنولوژی‌ها و ابزارها- **فریمورک**: Django- **پایگاه‌داده**: SQLite / PostgreSQL- **زبان‌های برنامه‌نویسی**: HTML, CSS, JavaScript- **کتابخانه‌ها**: - Bootstrap - Django Rest Framework - jQuery---  

## 📅 راهنمای نصب و راه‌اندازیبرای راه‌اندازی پروژه، مراحل زیر را دنبال کنید:  

1. **کلون کردن مخزن**:  
 ```bash git clone https://github.com/username/django-online-shop.git cd django-online-shop ```  

2. **نصب وابستگی‌ها**:  
 ```bash pip install -r requirements.txt ```  

3. **اجرای migrations**:  
 ```bash python manage.py migrate ```  

4. **اجرای سرور محلی**:  
 ```bash python manage.py runserver ```  

**بازدید از وب‌سایت**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
