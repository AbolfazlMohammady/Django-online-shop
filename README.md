
## 📖 معرفی پروژه**Django Online Shop** یک فروشگاه اینترنتی مدرن و مقیاس‌پذیر است که برای ایجاد تجربه‌ای بی‌نظیر از خرید آنلاین طراحی شده است. این پروژه با استفاده از فریمورک معتبر Django توسعه یافته و امکاناتی متنوع را برای مشتریان و مدیران فروشگاه فراهم می‌کند.  

---  

## 🛠️ ویژگی‌های کلیدی### برای کاربران:  

- **جستجوی پیشرفته**: - پیدا کردن محصولات براساس نام، دسته‌بندی و مشخصات به‌راحتی.  
- **سبد خرید**:  
 - امکان مدیریت محصولات دلخواه و مشاهده قیمت نهایی.  

- **پرداخت آسان**:  
 - ادغام با درگاه‌های پرداخت معتبر و تجربه‌ی خرید امن.  

### برای مدیران:  

- **مدیریت محصولات**:  
 - افزودن، ویرایش و حذف محصولات بدون هیچ‌گونه پیچیدگی.  

- **تجزیه و تحلیل اطلاعات**:  
 - دریافت آمار و تجزیه و تحلیل فروشگاه به کمک داشبورد مدیریتی.

## 🌟 طراحی و تکنولوژی‌ها- **فریمورک**: Django- **پایگاه‌داده**: SQLite / PostgreSQL- **واسط کاربری**: - HTML, CSS, JavaScript - Bootstrap برای طراحی ریسپانسیو و مدرن- **کتابخانه‌های مورد استفاده**:  
 - Django Rest Framework - jQuery - و ...

## 📅 راهنمای شروعبرای شروع کار با پروژه، مراحل زیر را دنبال کنید:  

1. **کلون کردن مخزن**:  
 ```bash git clone https://github.com/username/django-online-shop.git cd django-online-shop ```  

2. **نصب وابستگی‌ها**:  
 ```bash pip install -r requirements.txt ```  

3. **اجرای migrations**:  
 ```bash python manage.py migrate ```  

4. **اجرای سرور محلی**:  
 ```bash python manage.py runserver ```  

بازدید از [http://127.0.0.1:8000](http://127.0.0.1:8000) برای مشاهده فروشگاه.
